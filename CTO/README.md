# Indonesian-English Vocabulary Game

A comprehensive web-based vocabulary learning game that helps users learn Indonesian and English words through multiple interactive game modes.

## 🎮 Features

### Core Game Features
- **Language Toggle**: Switch between English → Indonesian and Indonesian → English learning modes
- **Difficulty Levels**: Three levels (Easy, Medium, Hard) with progressively challenging vocabulary
- **Multiple Game Types**: Four different learning modes to suit various learning preferences
- **Progress Tracking**: Comprehensive statistics including score, streak, accuracy, and words learned
- **Adaptive Difficulty**: System automatically adjusts based on user performance
- **Daily Challenges**: Set learning goals with progress tracking

### Game Modes

#### 1. 📚 Flashcards
- Click to reveal translations
- Includes pronunciation guides
- Perfect for visual learners

#### 2. ❓ Multiple Choice
- Select the correct translation from 4 options
- Immediate feedback on answers
- Builds recognition skills

#### 3. 🔗 Matching
- Match words with their translations
- Interactive drag-and-drop style interface
- Enhances association learning

#### 4. 🎧 Listening
- Audio simulation (button press feedback)
- Choose correct translation based on "heard" word
- Prepares for real audio-based learning

### Learning Features
- **30 Total Words**: 10 words per difficulty level
- **Pronunciation Guides**: Every word includes phonetic pronunciation
- **Vocabulary Categories**: From basic (house, water) to advanced (entrepreneurship, sophisticated)
- **Performance Analytics**: Track accuracy, learning progress, and improvement over time

### Gamification Elements
- **Level System**: Beginer → Intermediate → Advanced → Expert → Master
- **XP Points**: Earn experience points for correct answers
- **Streak Bonuses**: Consecutive correct answers earn bonus points
- **Leaderboard**: Compete with other players
- **Achievement Tracking**: Monitor words learned and progress milestones

### User Experience
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Modern UI**: Clean, intuitive interface with smooth animations
- **Settings Panel**: Customize username, difficulty, and language preferences
- **Local Storage**: Progress automatically saved between sessions
- **Visual Feedback**: Immediate visual confirmation for correct/incorrect answers

## 🚀 How to Play

1. **Open the Game**: Simply open `index.html` in any modern web browser
2. **Choose Settings**: 
   - Select difficulty level (Easy/Medium/Hard)
   - Choose language direction (English → Indonesian or vice versa)
   - Enter your username in settings
3. **Select Game Mode**: Choose from Flashcards, Multiple Choice, Matching, or Listening
4. **Start Learning**: Follow the on-screen instructions for each game mode
5. **Track Progress**: Monitor your statistics and daily challenge progress in the sidebar

## 🏆 Scoring System

- **Flashcards**: 5 points per correct answer
- **Multiple Choice**: 10 points per correct answer
- **Matching**: 15 points per correct pair
- **Listening**: 10 points per correct answer
- **Streak Bonus**: +2 points per consecutive correct answer (up to +20)
